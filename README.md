📌 Project: Restaurant Billing System

🔹 Overview
The Restaurant Billing System is a Python-based application designed to streamline the order management and billing process for restaurants. This system allows restaurant staff to select menu items, calculate totals (including taxes), generate receipts, and store transaction details in a database. The project enhances efficiency by automating billing, reducing manual errors, and improving record-keeping.

🔹 Features
✅ User-friendly GUI: A modern interface built using Tkinter with dropdown menus, tables, and buttons.
✅ Menu Management: Allows users to select food items, set quantities, and view order details.
✅ Automated Billing: Calculates subtotal, tax (5%), and final total automatically.
✅ Receipt Generation: Displays a structured bill summary and provides an option to print it.
✅ Database Integration: Stores order details using MySQL for transaction history tracking.
✅ Error Handling: Prevents incorrect inputs and ensures smooth processing.

🔹 Technologies Used
Programming Language: Python
GUI Framework: Tkinter (Enhanced with ttkbootstrap for modern styling)
Database: MySQL (for storing order history)
Concepts Applied: Object-Oriented Programming (OOP), File Handling, Data Validation

🔹 How It Works
1️⃣ Select a food item from the dropdown menu.
2️⃣ Enter the quantity and click "Add to Order."
3️⃣ The system displays the order summary in a structured table.
4️⃣ Click "Calculate Total" to compute the final bill (with tax).
5️⃣ Click "Generate Receipt" to display a printable bill and save the order in the database.
6️⃣ Click "Reset" to start a new order.

🔹 Learning Outcomes

📌 Understanding of database operations using MySQL (CRUD - Create, Read, Update, Delete).
📌 Implementation of billing calculations, receipt generation, and error handling.
